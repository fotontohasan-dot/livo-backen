# sports-api

**এই সার্ভিসটি প্রোডাকশনের অংশ নয়।**

মূল অ্যাপ্লিকেশন হলো রিপোজিটরির রুটে থাকা Express/EJS অ্যাপ (`node app.js`)।
সেটি এই ফোল্ডারের কোনো কিছু ইমপোর্ট বা প্রক্সি করে না — যাচাই করা হয়েছে,
`app.js`, `render.yaml` বা `package.json`-এর কোথাও `sports-api`-র উল্লেখ নেই।

## কেন এই নোট

`/api/predict` রুটটি আগে সম্পূর্ণ উন্মুক্ত ছিল:

```js
app.post("/api/predict", (req, res) => {
  const { matchId, userId, pick } = req.body;   // userId ক্লায়েন্টের দেওয়া
  predictions[matchId][userId] = pick;          // যাচাই ছাড়াই লেখা
```

কেউ ভুল করে এটি ডিপ্লয় করলে যে কেউ যেকোনো `userId`-এর প্রেডিকশন লিখতে বা
বদলে দিতে পারত। প্রমাণীকরণ ছিল না, রেট-লিমিটও নয়।

## এখন যা আছে

- লেখার রুটে (`POST /api/predict`) `x-api-key` হেডার বাধ্যতামূলক
- `SPORTS_API_KEY` সেট না থাকলে **সার্ভিসটি চালুই হয় না** (`process.exit(1)`)
- পড়ার রুট (স্কোর, ট্যালি) আগের মতোই পাবলিক — ওগুলোতে ব্যক্তিগত ডেটা নেই

## ডেটা কোথায় থাকে

প্রেডিকশন শুধু মেমোরিতে (`const predictions = {}`) — রিস্টার্টে মুছে যায়,
একাধিক ইনস্ট্যান্সে শেয়ার হয় না। অর্থাৎ এটি প্রোটোটাইপ, প্রোডাকশন স্টোর নয়।

## সিদ্ধান্ত নেওয়া দরকার

এই সার্ভিসটি সত্যিই দরকার কি না ঠিক করুন:

- **দরকার নেই** → ফোল্ডারটি মুছে ফেলুন। কোড থাকলে কেউ না কেউ একদিন ডিপ্লয়
  করবে।
- **দরকার আছে** → প্রেডিকশন মূল অ্যাপের ডাটাবেসে সরান এবং সেখানকার সেশন
  থেকে পরিচয় নিন, আলাদা সার্ভিস ও শেয়ার্ড কী-র বদলে।
