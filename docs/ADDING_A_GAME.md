# নতুন গেম যোগ করার নিয়ম

গেম যোগ করা এখন দুই ধাপের কাজ। **নিয়ম একটাই: সার্ভার-সাইড লজিক না থাকলে গেম
খেলা যাবে না।** ক্যাটালগে নাম বসিয়ে দিলেই গেম লাইভ হয় না — ইচ্ছাকৃতভাবে।

## কেন এই নিয়ম

আগে `routes/games.js`-এ দুটো আলাদা তালিকা ছিল — ১১৮টি গেমের নাম, আর ৭টি
হ্যান্ডলার। নাম আছে কিন্তু হ্যান্ডলার নেই, এমন গেম একটা fallback-এ চলে যেত:

```js
winAmount = secureRandom.chance(0.45) ? betAmount * 2 : 0;
```

অর্থাৎ ১০৯টি গেম আসলে একই জেনেরিক নিয়মে সেটেল হতো। ইউজার Blackjack, Sakura
Fortune, Lightning Roulette — আলাদা আলাদা গেম দেখত, কিন্তু সার্ভারে সবগুলোর ফল
একই ৪৫% হারে ঠিক হতো। আসল টাকার প্ল্যাটফর্মে এটা গ্রহণযোগ্য নয়, তাই fallback
সরানো হয়েছে।

## ধাপ ১ — লজিক লিখুন

`services/gameRegistry.js`-এর `HANDLERS`-এ যোগ করুন:

```js
'my-new-game': (betAmount, selection) => {
  const outcome = secureRandom.pick(['A', 'B']);
  const winAmount = outcome === selection ? betAmount * 1.95 : 0;
  return { winAmount, gameResult: { outcome } };
},
```

**নিয়ম:**

- এলোমেলো ফলের জন্য **সবসময়** `secureRandom` — কখনো `Math.random()` নয়
- রিটার্ন করতে হবে `{ winAmount, gameResult }`
- `winAmount` = ইউজার যা ফেরত পাবে (বাজি সহ), শূন্য হলে হার
- `gameResult` = যা ইউজারকে দেখানো হবে (কার্ড, নম্বর, রিল)
- ক্লায়েন্ট থেকে আসা `selection` যাচাই করুন — অপ্রত্যাশিত মান এলে হার ধরুন
- হ্যান্ডলারে DB কল বা `await` নয় — শুধু বিশুদ্ধ হিসাব

## ধাপ ২ — ক্যাটালগে নাম

একই ফাইলের `CATALOGUE`-এ:

```js
"my-new-game": "My New Game",
```

ব্যস। `isPlayable()` এখন `true` ফেরত দেবে, লবিতে কার্ড ক্লিকযোগ্য হবে,
`POST /games/play` বাজি নেবে।

## লবিতে দেখানো

লবির গেম তালিকা আসে `games` টেবিল থেকে (অ্যাডমিন প্যানেল → গেম)। সেখানে
`slug` অবশ্যই `CATALOGUE`-এর সাথে হুবহু মিলতে হবে।

- **লজিক আছে** → কার্ড স্বাভাবিক, ক্লিক করলে গেম খোলে
- **লজিক নেই** → কার্ড ধূসর, ব্যাজে "শীঘ্রই", ক্লিক নিষ্ক্রিয়

অর্থাৎ অ্যাডমিন প্যানেল থেকে গেম যোগ করলে সেটা লবিতে দেখা যাবে, কিন্তু লজিক
না লেখা পর্যন্ত কেউ টাকা হারাবে না।

## Crash ধরনের গেম

Aviator/crash-game আলাদা — বাজি ও ক্যাশআউট দুই ধাপে। এদের হ্যান্ডলার নেই;
`routes/games.js` নিজেই `game_rounds` টেবিলে রাউন্ড তৈরি করে ও সেটেল করে।
নতুন crash গেম হলে `CRASH_GAMES`-এ slug যোগ করুন।

## চালানোর আগে

```bash
npx jest tests/gameRegistry.test.js
```

টেস্ট নিশ্চিত করে: হ্যান্ডলার ছাড়া গেম কখনো খেলার যোগ্য হয় না, আর জেনেরিক
fallback ফিরে আসেনি।
