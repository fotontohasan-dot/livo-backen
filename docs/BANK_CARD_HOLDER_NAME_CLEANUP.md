# bank_cards.holder_name ক্লিনআপ (মালিকের জন্য ধাপে ধাপে)

**কেন:** কার্ড-যোগ ফর্মের "পাসওয়ার্ড" ঘরের মান `bank_cards.holder_name`-এ সাধারণ টেক্সটে জমা হতো। এই স্ক্রিপ্ট সেগুলো সরিয়ে ফেলে এবং আক্রান্ত ইউজারদের পাসওয়ার্ড বদলাতে বাধ্য করে।
স্ক্রিপ্ট: `scripts/cleanupBankCardHolderName.js` — **কোনো ডেটা (নাম/মান/ইউজার আইডি/DB URL) লগে বা আউটপুটে ছাপে না, শুধু সংখ্যা।**

## ধাপ
1. **আগে staging-এ** (staging DB-র `DATABASE_URL` দিয়ে) চালান। প্রোডাকশনে সরাসরি নয়।
2. নতুন কোড ডিপ্লয় হয়ে migration চলেছে কি না দেখুন (`users.must_reset_password` কলাম তৈরি হয়; স্ক্রিপ্ট নিজেও `IF NOT EXISTS` দিয়ে নিশ্চিত করে)। **`--apply`-এর আগে নতুন কোড ডিপ্লয় থাকতে হবে**, নইলে ফ্ল্যাগ বসলেও কেউ আটকাবে না (শুধু সেশন বাতিল হবে)।
3. Render Shell-এ (বা `DATABASE_URL` সেট করা টার্মিনালে) **DRY-RUN** (ডিফল্ট — কিছুই বদলায় না):
   `node scripts/cleanupBankCardHolderName.js`
   আউটপুট: `আক্রান্ত row: N, আক্রান্ত ইউজার: M`
4. সংখ্যা যুক্তিসংগত হলে ডেটাবেসের একটি ব্যাকআপ/স্ন্যাপশট নিন, তারপর:
   `node scripts/cleanupBankCardHolderName.js --apply`
   এটি একটাই ট্রানজ্যাকশনে: ব্যাকআপ টেবিল `bank_cards_holder_name_backup`-এ কপি → `holder_name` ফাঁকা (NULL) → আক্রান্ত ইউজারের `must_reset_password=true`। ব্যর্থ হলে সব rollback।
   commit-এর পর পুরনো সেশন বাতিল হয় (বিদ্যমান `revokeAllOtherSessions` + Redis সেশন স্টোরে `livo:sess:*`)।
5. যাচাই: আবার dry-run চালান → `আক্রান্ত row: 0` আসতে হবে। আক্রান্ত ইউজার লগইন করলে পাসওয়ার্ড-বদল পাতায় যাবে; বদলালেই ফ্ল্যাগ মুছে যায়।
6. ⚠️ ব্যাকআপ টেবিলে পুরনো (সংবেদনশীল) মান আছে। অ্যাক্সেস সীমিত রাখুন, প্রয়োজন শেষে (যেমন ৭–৩০ দিন পর, মালিকের সিদ্ধান্তে) `DROP TABLE bank_cards_holder_name_backup;` দিয়ে মুছুন।
7. ⚠️ আক্রান্ত ইউজার যদি অন্য সাইটেও একই পাসওয়ার্ড ব্যবহার করে থাকেন, তাঁদের জানানোর সিদ্ধান্ত মালিকের।

## সীমাবদ্ধতা
- "আক্রান্ত" = `holder_name` অ-ফাঁকা এমন প্রতিটি row (নাম আর পাসওয়ার্ড আলাদা করা সম্ভব নয়)। `/profile/security/bank` ফর্মে যোগ করা বৈধ নামও ফাঁকা হবে (ব্যাকআপ থেকে ফেরত মেলে)।
- ফর্ম/রুট এখনো `holder_name`-এ পাসওয়ার্ড-ইনপুট জমা করে — ক্লিনআপের সাথে ফর্মটিও ঠিক করা দরকার (এই PR-এ নয়)।
